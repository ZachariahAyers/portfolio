To test locally, update your Lambda function's CORS headers to include localhost:

const headers = {
  'Access-Control-Allow-Origin': '*', // Temporary for testing
  'Access-Control-Allow-Headers': 'Content-Type',
  'Access-Control-Allow-Methods': 'POST, OPTIONS'
};

OR for production + local:

const allowedOrigins = ['https://zachayers.io', 'http://localhost:5173'];
const origin = event.headers?.origin || event.headers?.Origin;

const headers = {
  'Access-Control-Allow-Origin': allowedOrigins.includes(origin) ? origin : allowedOrigins[0],
  'Access-Control-Allow-Headers': 'Content-Type',
  'Access-Control-Allow-Methods': 'POST, OPTIONS'
};

After updating Lambda, remember to SAVE and wait a few seconds for changes to propagate.
